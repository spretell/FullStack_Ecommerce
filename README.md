## Project Features

- Full-stack eCommerce style application
- React frontend built with **Vite**
- Express backend with RESTful API routes
- MySQL database integration
- Products dynamically loaded from database (`GET /api/products`)
- Contact form saves submissions to database (`POST /api/messages`)
- Mobile slide-out navigation menu
- Slide-out cart interface using React Context API
- Product filtering & sorting (category + price)
- Custom responsive design (mobile, tablet, desktop)
- Accessibility-friendly semantic structure
- Environment variables using `dotenv`
- Proxy configuration between Vite and Express
- Built with React, Node.js, Express, MySQL, Git, and CSS

## Database Structure

### 🧇 Products Table

Stores all mix product data including:

- `id`
- `name`
- `description`
- `price`
- `category`
- `image`

### 🥞 Messages Table

Stores contact form submissions:

- `id`
- `name`
- `email`
- `topic`
- `order`
- `subscribe`
- `message`
- `created_at`

## How to Run Locally

### 1. Install dependencies

Inside `client`:

```bash
npm install
```

Inside `server`:

```bash
npm install
```

### 2. Start backend

```bash
cd server
npm run dev
```

Backend runs on:

```
http://localhost:5001/
```

### 3. Start frontend

```bash
cd client
npm run dev
```

Frontend runs on:

```
http://localhost:5173/
```
